## Первый запуск работы

Код приложения и предметные команды ещё не определены. Первая задача должна уточнить продукт, границы решения и способ проверки, затем заполнить начальные документы и превратить AGENTS.md в карту именно этого проекта: пользователи, реальные части, источники правил и нужные проверки.

```powershell
python scripts/check_project.py
python scripts/check_project.py --ready
```

Нужен Python 3.11 или новее только для служебной проверки. Он не задаёт технологию приложения. Первая команда проверяет порядок документов. Вторая также обнаруживает незаполненные сведения начала проекта и до их заполнения завершается с ошибкой.

Для обычной задачи используется одна [карточка](docs/tasks/TEMPLATE.md) по [правилам ведения задач](docs/tasks/README.md). В ней сохраняются решение, выполненные действия, доказательства и следующий шаг.
