# Исторический архив

Архив хранит завершённые карточки, исследования и материалы на конкретную дату. Он не является описанием текущего поведения. Действующие сведения находятся в [навигаторе](../README.md).

- Завершённые карточки размещаются в `tasks/` внутри этого каталога; каталог создаётся по мере необходимости.
- Другие материалы группируются по реальной потребности. Укажите дату, статус и причину сохранения.
- Не переписывайте старый план так, будто он всегда описывал нынешнюю систему.
- После переноса исправляйте ссылки из действующих документов.
- Секреты и рабочие пользовательские данные не становятся допустимыми для хранения после переноса в архив.

Проверка структуры не обходит содержимое архивных документов. Отсутствие ошибок этой проверки не подтверждает актуальность исторического материала.
