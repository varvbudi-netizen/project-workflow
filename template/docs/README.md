В корне `docs/` находятся действующие документы. Новый справочник зарегистрируйте в таблице и укажите статус и дату. Развёрнутую историю храните в `archive/`, текущую работу — в `tasks/`. Иллюстрации при необходимости размещайте в `assets/`.

Не создавайте второй документ с теми же текущими фактами. Если предмет вырос, выделите профильный справочник и оставьте ссылку вместо дубликата. Для нового каталога документации также обновите разрешённую структуру в проверяющем сценарии.
