# Сопровождение комплекта шаблонов

Это отдельный проект со стартовым комплектом для других проектов. Начинайте с [README.md](README.md). Причины устройства описаны в [WORKFLOW.md](WORKFLOW.md) и [исследовании](AI-SOLUTION-RESEARCH.md).

- Копируемый источник находится в `template/`. Значения в двойных фигурных скобках предназначены для подстановки создателем проекта.
- Документы внутри `template/` описывают будущий проект. Их незаполненные сведения не являются сведениями о текущем комплекте.
- Поддерживайте один создатель проекта и один копируемый сценарий проверки. Не добавляйте систему расширений без реальной задачи.
- Создатель проекта не должен менять существующие каталоги, публиковать данные или выполнять команды из подставленного текста.
- Объяснения, комментарии к коду и сообщения пользователю пишите по-русски.
- Существенные проверки: создание проекта, запуск копируемой проверки, отказ от перезаписи, обнаружение сломанной ссылки и незаполненных сведений.
- Команды проверки приведены в README. При изменении состава образца обновляйте навигатор и перечень обязательных файлов.
- Не изменяйте другие проекты ради сопровождения этого комплекта.
